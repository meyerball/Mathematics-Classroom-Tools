Experiments, Outcomes & Sample Space

Let's learn the three essential words used in every probability problem.

1. Chance Experiment

An activity where the result is uncertain (e.g., rolling a die, flipping a coin).

2. Outcome

A single possible result of an experiment (e.g., rolling a 4, or flipping Heads).

3. Sample Space

A list of ALL possible outcomes, usually written inside curly brackets: { ... }
